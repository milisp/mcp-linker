# Pricing

MCP Linker is free and open source (AGPL-3.0). Viewing every client is free,
and managing servers in Claude Desktop and Cursor is free.

Personal and Pro are one-time purchases that unlock managing every other
client (Claude Code, Codex, GitHub Copilot, OpenCode, Augment and the rest),
copying between Claude Code projects, batch actions, and live tool inspection. Personal includes a year of updates; Pro includes
lifetime updates and a commercial use license.

See [mcp-linker.milisp.dev/pricing](https://mcp-linker.milisp.dev/pricing).
