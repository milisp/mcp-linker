# Pricing

MCP Linker is free and open source (AGPL-3.0). Viewing every client is free,
and managing servers in Claude Desktop and Cursor is free.

Plus and Pro are one-time purchases, each with a year of updates; the version
you have keeps working forever.

- Plus unlocks every other client (GitHub Copilot, OpenCode, Augment, Cline
  and the rest), sync, batch actions, and live tool inspection.
- Pro adds Claude Code (every scope) and Codex, copying between Claude Code
  projects, and priority support.

See [mcp-linker.milisp.dev/pricing](https://mcp-linker.milisp.dev/pricing).
